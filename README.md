

# 배고픔 페어틀

#### 페어틀, 다인틀, 메인트, 헤더 등의 편집을 손쉽게

편집 프로그램 없이도 페어틀, 다인틀, 메인트, 헤더 등의 편집을 손쉽게 할 수 있도록 지원합니다.

##### 주요 기능

> 내보내기: 다른 기기, 다른 사람에게 파일을 넘겨 이어서 편집할 수 있습니다.

> 저장슬롯: 다양한 페어를 저장하고, 관리할 수 있습니다.

> 스티커: 페어틀 이외의 이미지를 추가하여 꾸밀 수 있습니다.

> 출처표기: 커미션 등 타인이 그린 그림의 출처를 간편하게 남겨보세요.

> 자유로운 수정: 제작한 이미지는 비상업적인 용도 선에서 자유롭게 수정하고 사용할 수 있습니다.

> 모바일 지원: 모바일 환경에서 페어틀 편집이 어려웠던 점을 개선하였습니다.

> 자동저장: 페어틀을 꾸미다 튕겨도, 마지막 작업이 저장됩니다.
